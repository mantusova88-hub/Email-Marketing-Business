# Fragen & Antworten: Claude Code Q&A Call

*Zoom-Community-Call vom 22.04.2026*

## Grundlagen: Was du brauchst

**Was brauche ich am Anfang, um mit Claude Code zu starten?**
Ihr braucht die Claude-App, das orange Kästchen. Da gibt es drei Bereiche: Chat, Co-Work und Code. Ich arbeite ausschließlich mit Code. Mit Co-Work und Chat arbeite ich gar nicht.

**Ist die Ordnerstruktur wichtig, die du vorgegeben hast?**
Nein, die ist nicht wichtig. Das war einfach nur von mir nett gemeint, damit ihr einen Startpunkt habt. Wenn das Kopieren nicht klappt: don't worry. Sagt einfach zu Claude Code: »Erstell mir bitte eine sinnvolle Ordnerstruktur und pack meine Infos in die passenden Ordner.« Das läuft dann genauso.

**Ist Claude Code kostenlos?**
Nein, Claude Code ist nicht kostenlos. Der Plan kostet 19 Euro.

**Was ist der Unterschied zwischen Claude und Claude Code?**
Claude ist ein Chatprogramm, Claude Code ist ein Programmierprogramm. Wenn du allgemeine Fragen stellen willst: Claude. Wenn du programmieren willst: Claude Code.

**Soll ich lieber Chrome oder Safari nutzen?**
Auf jeden Fall Chrome. Ich benutze Chrome als Standardbrowser.

## Ordner, Speicherung & GitHub

**Macht es einen Unterschied, ob ich den Ordner auf dem Desktop oder in Dokumenten liegen habe?**
Nein, ist egal.

**Gibt es einen Grund, die Ordnerstruktur nicht auf iCloud zu legen?**
Ja. iCloud ist super unsicher. Wenn dein Account mal gehackt wird, ist deine ganze Datenbank weg. Deswegen bin ich heute Morgen auch nochmal umgezogen. Ich mache das lieber offline — und mit GitHub haben wir ja trotzdem die Möglichkeit, online zu sichern.

**Brauche ich GitHub?**
Nein, niemand von euch braucht GitHub zwingend. GitHub ist einfach ein Tool, das eure Ordner online speichert, damit die Dateien noch da sind, falls dein Laptop mal geklaut wird. Macht aber natürlich Sinn, das zu nutzen.

**Was ist der Unterschied zwischen Git und GitHub?**
Zwei verschiedene Sachen. Git ist ein Programm, das du brauchst, damit Claude Code sauber läuft — bei Macs meist schon vorinstalliert, bei Windows musst du es runterladen. GitHub ist der Online-Dienst, wo deine Dateien liegen.

**Muss GitHub auf Windows installiert werden?**
Nein, GitHub braucht niemand zwingend. Git schon — das ist bei Windows normalerweise nicht vorinstalliert.

**Speichert Claude bei dir alles automatisch im GitHub-Ordner?**
Genau, das habe ich gerade programmiert. Ich habe einfach gesagt: »Ich bin faul, mach du das bitte automatisch. Ich möchte nicht jedes Mal an /shutdown denken.« Dann macht er das jetzt automatisch.

**Kann ich mich auf einem anderen Rechner anmelden und habe den ganzen Verlauf?**
Ja, wenn ihr GitHub habt. Dann könnt ihr beide Rechner auf dieses Repository zugreifen lassen.

**Habe ich zwei Firmen — soll ich zwei unterschiedliche Ordner anlegen?**
Ja, genau. Und dann sagst du Claude einfach: Wenn ich Firma A sage, leg es in Ordner A ab. Wenn ich Firma B sage, in Ordner B.

**Ich bekomme die Fehlermeldung »Git ist für Verknüpfung erforderlich«, obwohl GitHub installiert ist.**
Git und GitHub sind was anderes. Du musst wahrscheinlich Git zusätzlich installieren.

## /start, /shutdown und Befehle

**Bei mir funktioniert /start und /shutdown nicht — es heißt, das geht nur im Claude Code Terminal.**
Ihr müsst das Terminal gar nicht nutzen. Das Terminal ist verwirrend und macht für mich keinen Sinn, wenn wir die App haben. Wenn Claude sagt, er braucht /start nicht und kann über die Ordnerstruktur eh zugreifen, dann vertrau ihm einfach. Ihr müsst nicht mit diesen Befehlen arbeiten.

**Macht es Sinn, alle Hintergrundinformationen selbst in die Ordnerstruktur einzufügen?**
Nee, macht es nicht. Ich habe ihm am Anfang gar nichts über mich gesagt. Ich habe nur gesagt: »Wenn ich dir was Privates erzähle, pack das bitte in den passenden Ordner ab.« Dann hat er einfach angefangen. Ich habe dann irgendwann meine YouTube-Videos transkribieren lassen — und er hatte auf einmal krass viel Wissen über mich. Also: macht euch da keinen Kopf.

**Fehlermeldungen beim Startbefehl — wie löse ich das?**
Frag einfach Claude, was die Fehlermeldung bedeutet. Ansonsten: du musst eh nicht mit /start arbeiten.

## Webseiten bauen (Netlify & Co.)

**Kann ich eine komplett neue Webseite ohne Vorlage mit Claude Code erstellen — z.B. in WordPress?**
Ob das direkt in WordPress geht, weiß ich nicht. Ich habe gestern eine komplette Webseite erstellt — mit »Über mich«, Angeboten, gratis Downloads, Impressum, Datenschutz, Calendly-Buchung. Innerhalb von 10 Minuten. Ich nutze dafür Netlify. Ob man direkt in WordPress bauen kann — weiß ich nicht, probier's aus.

**Was ist Netlify — ist das wie Elementor?**
Nein. Netlify ist ein Programm, das deine Codes (z.B. HTML) in klickbare Webseiten verwandelt. Es macht deine Projekte quasi als Landing Page sichtbar.

**Nach der Erstellung der Seite mit Claude Code — wie mache ich sie sichtbar?**
Über Netlify.

**Brauche ich trotzdem eine Domain?**
Nicht mehr zwingend. Wenn du mit deinepunktnetlify.app leben kannst — cool. Ich finde juliatrost.de einfach schöner und professioneller. Aber Pflicht ist es nicht.

**Bietet Netlify nur Landing Pages, die ich mit meiner Website verlinke?**
Nein. Netlify verwandelt HTML-Codes in klickbare Websites. Das können auch komplette Webseiten sein, nicht nur Landing Pages.

**Kann ich den Bezahl-Button auf meiner Netlify-Seite mit meiner Checkout-Seite verknüpfen?**
Ja. Du sagst Claude einfach: »Pack hinter diesen Button den Link zu meiner Checkout-Seite.« Ich habe das genauso gemacht — Early-Bird-Ticket, VIP-Ticket. Du kannst auch Pixel hinterlegen.

**Funktioniert Netlify dann auch mit ClickTipp oder Digistore?**
Weiß ich nicht, probier's aus. Ich kann dir nicht sagen, was mit welcher Firma zusammenarbeitet.

**Ich habe meine Homepage auf Squarespace. Macht es Sinn, zu wechseln, um programmierte Seiten hochladen zu können?**
Ich kenne nicht jedes Tool. Frag genau das: »Kann ich bei Squarespace meine programmierten Seiten hochladen? Wenn nicht, macht es Sinn, zu WordPress zu wechseln?« Claude sagt dir das.

**Gibt es eine Lösung mit unlimitierter Nutzung, wenn man nicht die private Adresse im Impressum nutzen möchte?**
Ehrlich? Macht doch einfach die private Adresse. Dieses »aber was wenn jemand kommt« — das macht doch niemand. Das ist Angstleben. Als Unternehmer musst du mit einem gewissen Risiko leben. Wenn du unbedingt willst: du kannst online eine Postadresse erstellen, mache ich z.B. für meine amerikanische Firma. Würde ich aber privat nicht machen.

## Content-Erstellung: Carousels, Reels, Videos

**Welche Tools braucht man, damit Claude Videos schneidet?**
Frag einfach Claude Code: »Bitte schneide mir Videos.« Dann sagt er dir, was er braucht. Das ist das Geniale — alles, was ihr an Fragen habt, könnt ihr ihm direkt stellen.

**Kapiert Claude Code automatisch, was in einem Video geschnitten werden soll?**
In den meisten Fällen ja. Und wenn nicht, sagst du halt: »Nein, bitte anders, mach das und das.« Mit ihm arbeiten heißt: iterieren.

**Claude Code sagt, er kann nicht automatisiert Reels posten. Wie funktioniert das?**
Für automatisches Posten brauchst du ein Drittanbieter-Tool. Ich nutze Plotato (19 €/Monat). Wenn dir das zu teuer ist: Claude die Inhalte erstellen lassen und manuell hochladen.

**Für den Maxplan / Proplan: reicht Pro für automatisierte Carousels?**
Weiß ich nicht, probier's aus. Wahrscheinlich schaffst du damit nicht 10 Carousels, sondern eher 2. Ich weiß überhaupt nicht, wie sich die Tokens verteilen.

**Ich habe ein Insta-Profil zum Thema Dating und einen Affiliate-Course — kann ich mit Claude Code auch Reels erstellen, oder reichen Carousels?**
Reichweite kannst du mit Carousels, Reels und Werbeanzeigen aufbauen. Reels wirken am besten. Bei Dating/Beziehungs-Themen würde ich aber Talk-to-Head-Reels selbst machen — du musst da sichtbar sein, weil Vertrauen zentral ist. Wir vertrauen dir mit unserem Herz und unserer Seele. Da will ich dich sehen.

**Hast du einen erprobten Workflow für die Automatisierung von Instagram Reels?**
Für Talk-to-Head-Reels noch nicht — da traue ich der KI noch nicht, dass sie aussieht wie ich. Die mache ich weiterhin selbst. Für B-Roll-Reels ohne dich selbst: ja, einfach ein Template in Canva bauen, Claude Code den Prompt geben — »Erstell mir jede Woche ein Reel mit wechselnder Headline und wechselndem Hintergrund.«

**Wie verhindere ich, dass die Texte in Slides + Captions KI-generisch klingen?**
Gib Claude eine explizite Regel. Ich habe gesagt: »Schreib dir in all deinen Ordnerstrukturen ein: Du klingst niemals nach einer KI. Niemals Sachen wie ‚Das ist nicht das, sondern das.' Niemals ‚Hier ist, womit…'.« Das musst du ausdrücklich verbieten.

**Wird automatisch gepostet, oder kann ich einen Zwischenschritt machen?**
Nicht automatisch. Ich lege einen Zwischenschritt ein: Claude packt alle Carousel-Beiträge in einen Ordner. Ich schaue die an und schiebe die, die passen, in den Ordner, aus dem automatisch gepostet wird. Ich will mir überlegen, was ich wirklich raushaue.

**Kann man Videos hochladen, damit Claude auf die Infos zugreifen kann? Habe viele Infos in meinen Videos.**
Keine Videos auf euren Rechner — das wird sonst zu einem massiven Speicherproblem. Lass die Videos transkribieren und speichere nur die Transkripte.

**Wie kann ich Bildbearbeitungen/Bilder mit Claude Code machen?**
Bilder finde ich in Claude Code noch nicht so gut. Dafür nutze ich Manus (super günstig) — z.B. mit Nano Banana für Werbeanzeigen. Claude Code gibt mir einen Prompt raus, ich übergebe den an Manus.

## Excel, Tabellen & Automatisierungen

**Kann Claude mir eine Excel-Datei bauen?**
Ja, einfach sagen: »Erstell mir eine Excel mit zwei Tabellenblättern, einmal ‚heute', einmal ‚morgen', und schreib A=1, Z=2 rein.« Das funktioniert. Ihr könnt ihm auch einfach ein Screenshot reinwerfen (z.B. ein Etsy Social-Media-Planer) und sagen: »Nachbauen, als Excel-Datei.« I'm impressed — sieht mega aus.

**Wie kann die Excel einen schönen Look bekommen?**
Zwei Wege: Farben ändern mit »Pass die Farben an meine Brandfarben an.« Oder: Platzhalterbilder durch Bilder von mir ersetzen + Unicode-Zeichen zu Smileys ändern. Einfach Wünsche formulieren.

**Wenn du eine Routine herstellst, machst du das lokal oder remote?**
Ich weiß nicht genau, was du meinst — ich sage einfach: »Scrape einmal pro Tag meinen Instagram-Account und gib mir die zwei wichtigsten Learnings. Stell das als täglichen Task ein.« Claude speichert das unter Routinen. Ich habe keine Ahnung, wie er das technisch macht — ich sage einfach: mach.

**Kannst du auf deine Startroutine eingehen — wofür sind die?**
Ich habe keine Startroutine. Ich öffne ein Fenster, sage »Hi, ich will das und das machen.« Routinen links im Fenster sind einfach Sachen, die automatisch ablaufen: wöchentlicher Report, wöchentliche Carousels, tägliche Trend-Recherche usw.

**Hast du eine Idee zu Claude Code + Excel — oder jemand, der helfen kann?**
Ja, ich habe jemanden: Claude Code. Du brauchst niemanden mehr zu bezahlen für sowas.

## Ticketing, Zahlungen & Tools

**Wie kann ich Tickets mit QR-Code für mein Live-Event verkaufen, ohne dass mein Team manuell abhaken muss?**
Ich wusste das auch nicht und habe Claude gefragt. Er hat mir drei Wege aufgezeigt und dann Option 2 empfohlen: eigenes System über SamCart (Zahlungsplattform) + eigener Kassen-Service. Dann habe ich gesagt: »Was ist Kassen-Service?« — er erklärt mir alles Schritt für Schritt. Und zack: wir bauen unser eigenes Event-Ticketing-System. Hätte mich sonst tausende Euro bei einem Anbieter gekostet.

**Warum nutzt du SamCart und nicht FIVE?**
Weil FIVE bei mir nicht mehr richtig funktioniert hat.

**Brauche ich Plotato, um Automatisierungen zu erstellen?**
Nein. Plotato brauchst du nur, um automatisiert zu posten. Automatisierungen generell erstellst du direkt in Claude Code.

**Wofür braucht man Plotato, außer für automatisches Posten?**
Für gar nichts anderes. Nur zum automatisierten Posten.

**Ich habe ein KI-Tool erstellt, auf Netlify gehostet, API-Key von Anthropic hinterlegt, aber es zeigt kein Guthaben an.**
Prüf das Guthaben: Bei Anthropic (Claude.ai) und bei Netlify. Das kann eigentlich nur an einem von beidem liegen.

**Wie schütze ich meinen API-Key und die Token-Kosten, wenn Leute mein Tool nutzen?**
Ein Tool irgendwo testweise aufsetzen, Claude fragen: »Wie viele Tokens verbraucht ein Output?« — dann hochrechnen. Bei 200 Kunden × 3 Outputs = überschaubar, meist nur Taschengeld-Beträge. Ganz wichtig: API-Keys NIEMALS in den Chat packen. Immer in eine .env-Datei. Das kannst du Claude auch direkt sagen.

**Wenn ich ein Tool anlege, das andere nutzen — verbrauchen sie dann meine Credits?**
Ja. Der Ersteller zahlt immer die Credits.

## Chrome Extension, Whisperflow & Zusatz-Tools

**Wie kriege ich Claude mit der Chrome-Erweiterung verbunden?**
Chrome-Extension im Chrome Web Store installieren (Suchbegriff: »Chrome Extension Claude Code«). Dann immer auf das Puzzle-Symbol oben klicken und die Extension aktivieren. Danach hast du rechts ein Fenster.

**Ist zu Whisperflow und Chrome Extension etwas im Memberbereich hinterlegt?**

## Strategie & Mindset

**Wie gehe ich vor, wenn ich ganz am Anfang stehe — noch kein Content, keine Nische?**
Erst mit Claude Code an die Nische rangehen. Sag ihm einfach: »Ich bin komplett neu, habe keine Ahnung, will ein Business starten.« Dann macht er dir einen Plan: Thema finden, Marktforschung (welche Plattform ist sinnvoll? was ist nicht übersättigt? worauf hast du Bock?), dann anfangen zu posten. Raus damit. Sicherheit und Trust aufbauen dauert am längsten. Produkt entwickeln bevor du ein Profil hast? Macht keinen Sinn — dann hast du keine Käufer.

**Wird es Mindset zu Claude Code in 1–2 Jahren geben?**
Ja. Jeder wird damit programmieren. Das ist wie Bitcoin-Stand 2005 — diejenigen, die jetzt reingehen und dranbleiben, sind in ein paar Jahren die Profiteure.

**Wenn ich dir zuschaue, denke ich, ich bin der größte Technik-Horst — wie schaffst du das so schnell?**
Weil ich nicht lange überlege. Mein Kopf ist komplett ausgeschaltet — 90 % der Fragen hier hätte ich auch stellen können. Ich habe Claude Code auch erst vor 3 Wochen installiert, hatte keinen, den ich fragen konnte. Also habe ich Claude Code selbst gefragt. Das ist Hilfe zur Selbsthilfe. Kopf aus. Meine erfolgreichsten Kunden (50K/Monat) sind alle die, die gesagt haben: »Scheiß drauf, nicht nachgedacht, nachgebaut.« Die meisten meiner Kunden sind zu intelligent und haben zu viel Angst. Das Rad müsst ihr nicht neu erfinden — einfach kopieren.

**Soll ich umbranden oder einen neuen Instagram-Kanal starten (40K Follower, aber falsche Zielgruppe)?**
Das ist eine Business-Frage, die beantworte ich in Elevate. Hier geht's um Claude Code.
