## Woher kommen diese Dateien?

Diese Session läuft in einer Cloud-Umgebung ohne Zugriff auf deinen Mac (Desktop/Downloads). Die hier abgelegten Dateien stammen aus Google Docs, die Julia Trost direkt mit deinem Google-Konto geteilt hat — nicht aus deinen lokalen Mac-Ordnern.

**Falls du auf deinem Mac noch weitere Kursunterlagen von Julia hast** (z.B. eine vorgegebene Ordnerstruktur mit Business/Strategie/Personal-Kategorien, die nicht über Google Drive geteilt wurde), kann ich die nicht automatisch finden. Lade sie einfach direkt in den Chat hoch (Drag & Drop) — dann sortiere ich sie hier mit ein.
